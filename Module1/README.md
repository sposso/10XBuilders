Objectives:
1. Identify wheter we are using AI models with automation complancency. It implies over-reliance on automated systems leading to reduce vigilance, critical thinking or oversight.
  It causes several problems such as :
  - automation bias, when we tend to favor suggestions from automated systems even when they are wrong. 
  - Skill atrophy: we loss expertise due to reduced active engagement

2. Avoind using IA models with automation complacency using hybrid engineering. In this workflow, the human leads and AI implements.
To execute this workdlow, a structred loop named BPIR is proposed.

  BPIR is composed of 4 stages that must be carried out when working with AI:
  B -- Brief -> Human is responsible for definining a context, restrictions and defition of done. 
  P -- Plan  -> AI model propose a plan and human validates
  I -- Implementation  -> IA model generates code iteratively
  R -- Review -> Human audits the logic and secuirity of the implementation,  and accomplishment of the initial plan.
